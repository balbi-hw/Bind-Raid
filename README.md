# Bind Raid (CHAINBOUND RAID)

두 플레이어가 허리 사슬로 연결된 채 코끼리형 보스를 사냥하는 3D 3인칭 협동 레이드 게임의 기획 저장소입니다. 기본 전투는 몬스터 헌터형이며, 사슬의 위치·장력·공동 조작을 전투의 핵심으로 삼습니다.

## 기획 문서

- [조작감·전투 개선 실행 계획](docs/CHAINBOUND_RAID_Gameplay_Improvement_Plan.md): 1차 테스트 이후 개선 순서, 확장 가능한 코드 구조 원칙과 단계별 완료 기준

- [전체 게임 기획서 (GDD)](docs/CHAINBOUND_RAID_GDD.md): 핵심 경험, 전투·사슬·보스 시스템, UX와 장기 제작 범위
- [프로토타입 기획서](docs/CHAINBOUND_RAID_Prototype_Plan.md): 검증 목표, 수직 단면, 수용 기준, 테스트 계획과 일정

두 문서에는 기존 대화에서 확인된 방향을 **[확정]**, 새로 제안한 규칙을 **[제안]**, 플레이테스트로 검증할 수치를 **[가정]**으로 구분했습니다. 프로토타입 범위가 전체 기획과 다를 때는 프로토타입 기획서를 우선합니다.

## 현재 단계

현재 프로토타입은 Unity 6.3 LTS (`6000.3.27f1`)와 3D URP (`17.3.0`)를 사용합니다. 전용 서버가 게임 상태를 관리하고 두 플레이어가 클라이언트로 접속합니다. 원본 기획서에 엔진이 확정되어 있지는 않습니다.

## 1·2번 기능 확인

Unity에서 `Assets/Scenes/RaidSessionScene.unity`를 열거나 `Chainbound Raid > Build Client and Dedicated Server`로 빌드합니다. `Builds/Server/ChainboundRaidServer.exe`를 먼저 실행하고, 두 PC에서 `Builds/Windows/ChainboundRaid.exe`를 실행합니다. 각 클라이언트에서 서버 IP를 입력하고 **Join server**를 누릅니다. 같은 PC에서 시험한다면 기본 주소 `127.0.0.1`을 사용합니다. 두 사람이 **Toggle ready**를 누르면 2인 튜토리얼로 이동합니다. 사슬 거리, 자세, 공동 당기기, 낚아채기 대응, 회전 구조를 순서대로 완료하면 전투가 시작됩니다. 개발용 빌드에서는 튜토리얼 건너뛰기 버튼을 사용할 수 있습니다.

테스터용 클라이언트는 `Chainbound Raid > Build Tester Client`로 별도 빌드한 뒤 `tools/package_tester.ps1`로 압축합니다. 이 빌드에는 건너뛰기 버튼이 없습니다. 배포 절차와 조작은 [테스터 안내](docs/TESTER_GUIDE.md)를 참고하세요. 코끼리 보스 모델은 프로젝트 소유자가 직접 제작했고 테스터 빌드 공유를 허용했습니다.

개발용 클라이언트와 서버를 빌드한 뒤 `tools/run_regression.ps1`을 실행하면 튜토리얼·보스·구조·승리 4개 사례를 서버와 두 클라이언트에서 자동으로 확인합니다. 결과는 `Builds/Regression/`에 저장됩니다.

전투 조작은 WASD 이동, 마우스 시점, Shift 질주, Space 구르기, 왼쪽/오른쪽 클릭 약/강공격, Tab 부위 선택, E 동료 구조입니다. 현재 개발자 접속은 서버 IP와 UDP 7777 포트를 사용합니다. 외부 서버 배포·초대 코드·정식 튜토리얼은 아직 없습니다.

플레이어는 자신이 파란색, 동료가 주황색으로 보입니다. 공격은 노란색, 강공격은 주황색, 회피는 청록색, 피격·다운은 붉은색으로 표시되며, 바닥 링도 같은 색으로 바뀝니다. 보스가 발구르기를 준비하면 몸과 바닥 예고 링이 붉게 변합니다. 동작은 캐릭터별 설정으로 혼합 재생하며, 전용 클립이 없는 행동은 임시 자세 표현을 사용합니다.

3번 사슬 기능은 두 플레이어가 전투에 진입하면 자동으로 나타납니다. 사슬은 여유일 때 하늘색, 긴장일 때 노란색, 과긴장일 때 빨간색, 앞다리에 감기면 보라색입니다. 상태와 서버 판정 길이는 STATUS에 표시됩니다. 앞다리 지정점을 사슬 경로가 지나면 감기고, 멀어지면 해제됩니다. 움직임의 자연스러움은 후속 플레이테스트에서 조정할 예정입니다.

4번 협동 기능은 `Q`로 유연/고정 자세를 전환하고 `F`를 누르고 있는 동안 당기기를 시도합니다. 두 플레이어가 고정 자세와 유효 각도를 유지하며 앞다리에 사슬을 감고 동시에 당기면 제압 게이지가 오릅니다. 게이지가 차면 보스가 잠시 경직되고 같은 부위는 25초 동안 다시 제압할 수 없습니다. STATUS에 자세, 입력, 게이지, 대표 실패 이유를 표시합니다. 사슬 낚아채기 중에도 공동 당기기로 코를 경직시킬 수 있습니다.

5번 보스는 발구르기·돌진·코 휘두르기·사슬 낚아채기·한 명 회전을 사용합니다. 각 기술은 전조 표시 후 판정하며, 보스 HP 50% 이하에서 연계 빈도가 바뀝니다. 회전에 잡힌 플레이어는 `R`을 유지해 회전을 늦추고, 자유 플레이어는 초록색 구조 지점에서 `E`를 유지해 조기 구조할 수 있습니다.

6번 HUD는 오른쪽에 두 플레이어와 보스의 상태, 사슬·제압 게이지, 기술 대응 안내를 표시합니다. `1` 접근, `2` 당겨, `3` 해제, `4` 구조 핑을 보내며, `Esc` 설정에서 한국어/영어, 마우스 감도, 안내 글자 크기와 화면 흔들림을 즉시 바꿀 수 있습니다.
