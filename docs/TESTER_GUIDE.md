# CHAINBOUND RAID 테스트 안내

## 시작

1. 압축 파일을 원하는 폴더에 모두 풉니다. `ChainboundRaid.exe`만 따로 옮기지 마세요.
2. 서버 담당자가 전용 서버를 먼저 실행하고 서버 IP를 알려줍니다. 서버는 테스트 중 계속 켜져 있어야 합니다.
3. 두 테스터가 각각 `ChainboundRaid.exe`를 실행해 서버 IP를 입력하고 **Join server (port 7777)**를 누릅니다. 같은 PC에서 시험하면 `127.0.0.1`을 사용합니다. 다른 PC에서는 서버 PC의 IP를 사용합니다. 서버의 UDP 7777 포트에 접근할 수 있어야 합니다.
4. 두 사람이 **Toggle ready**를 누르면 2인 튜토리얼이 시작됩니다.

## 튜토리얼

화면 왼쪽의 목표를 순서대로 완료합니다. 두 사람의 진행 상태는 서버가 함께 관리합니다.

1. 사슬이 노란색으로 변할 때까지 멀어졌다가 다시 접근합니다.
2. 각자 `Q`를 눌러 고정 자세를 취하고, 다시 눌러 유연 자세로 돌아옵니다.
3. 파란색 **YOUR POSITION** 표식을 따라 보스 앞다리 양측에 서서, 두 사람이 `Q`로 고정 자세를 취하고 `F`를 함께 누릅니다. 실패하면 화면의 Hint를 확인합니다.
4. 사슬을 긴장시켜 낚아채기 연습을 시작합니다. 미리 가까워져 회피하거나, 잡힌 뒤 함께 당겨 대응합니다.
5. 두 번째 플레이어는 보스에 접근해 회전 연습을 시작하고 `R`로 저항합니다. 첫 번째 플레이어는 초록색 **RESCUE POINT**에서 `E`를 유지합니다.

다섯 단계를 모두 마치면 보스전이 시작됩니다.

## 전투 조작

`WASD` 이동, 마우스 시점, `Shift` 질주, `Space` 회피, 왼쪽/오른쪽 클릭 약/강공격, `Tab` 부위 선택, `Q` 자세 전환, `F` 공동 당기기, `E` 구조, `R` 회전 저항입니다.

## 알려진 범위

Windows 전용 프로토타입입니다. 현재는 서버 IP 직접 접속이며 초대 코드와 재접속 기능이 없습니다. 화면 안내는 한국어와 영어 중 선택할 수 있습니다. 이 패키지에는 개발용 튜토리얼 건너뛰기 버튼이 없습니다.

전사 플레이어 모델과 보스 모델은 프로젝트 소유자가 직접 제작했으며, 이 테스트 빌드에 포함할 수 있도록 허용했습니다. 모델 파일을 별도로 재사용할 권한이 제공되는 것은 아닙니다.

## 시점과 언어 설정

튜토리얼과 전투에서는 별도 클릭 없이 마우스를 움직이면 바로 시점이 회전합니다. `Esc`를 누르면 커서가 해제되어 설정을 클릭할 수 있고, 다시 `Esc`를 누르면 시점 조작으로 돌아갑니다.

설정의 **한국어 / English** 버튼으로 언어를 즉시 변경합니다. 선택은 다음 실행에도 유지됩니다. 최초 실행은 운영체제 언어가 한국어일 때 한국어, 그 외에는 영어로 시작합니다.

## 공격 타이밍

공격은 준비 동작 뒤 실제 타격 구간에 적중합니다. 보스를 향해 닿는 거리에서 휘둘러야 하며, `Tab`으로 선택해도 먼 부위에는 피해를 주지 않습니다. 약공격 후반에 다시 왼쪽 클릭하면 다음 공격을 예약할 수 있습니다. 회복 구간 후반에는 `Space`로 회피하여 공격을 끊을 수 있습니다. 강공격은 스태미나 15가 필요합니다.

## 개선된 조작과 표현

걷기·질주와 행동 전환을 부드럽게 혼합하며, 실제로 받은 피해에만 카메라 흔들림이 발생합니다. 록온은 선택한 부위를 추적하고 벽에 가까워지면 시점 거리를 줄입니다. `Esc` 설정에서 마우스 감도·안내 글자 크기·흔들림도 바꿀 수 있습니다.

보스는 거리와 사슬 상태에 맞춰 기술을 고르고 전조 중 점진적으로 방향을 맞춥니다. 회전 구조 지점은 보스 방향에 따라 이동하므로 현재 표시된 지점을 따라가세요. 일부 행동은 아직 전용 클립 대신 임시 자세 표현을 사용합니다.
