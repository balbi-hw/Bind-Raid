# CHAINBOUND RAID 테스트 안내

## 시작

1. 압축 파일을 원하는 폴더에 모두 풉니다. `ChainboundRaid.exe`만 따로 옮기지 마세요.
2. 서버 담당자가 전용 서버를 먼저 실행하고 서버 IP를 알려줍니다. 서버는 테스트 중 계속 켜져 있어야 합니다.
3. 두 테스터가 각각 `ChainboundRaid.exe`를 실행해 서버 IP를 입력하고 **Join server (port 7777)**를 누릅니다. 같은 PC에서 시험하면 `127.0.0.1`을 사용합니다. 다른 PC에서는 서버 PC의 IP를 사용합니다. 서버의 UDP 7777 포트에 접근할 수 있어야 합니다.
4. 두 사람이 **Toggle ready**를 누르면 2인 튜토리얼이 시작됩니다.

## 튜토리얼

화면 왼쪽의 목표를 순서대로 완료합니다. 두 사람의 진행 상태는 서버가 함께 관리합니다.

1. 사슬이 노란색으로 변할 때까지 멀어졌다가 다시 접근합니다.
2. 각자 `Q`를 눌러 고정 자세를 취하고, 다시 눌러 유연 자세로 돌아옵니다.
3. 파란색 **YOUR POSITION** 표식을 따라 보스 앞다리 양측에 서서, 두 사람이 `Q`로 고정 자세를 취하고 `F`를 함께 누릅니다. 실패하면 화면의 Hint를 확인합니다.
4. 사슬을 긴장시켜 낚아채기 연습을 시작합니다. 미리 가까워져 회피하거나, 잡힌 뒤 함께 당겨 대응합니다.
5. 두 번째 플레이어는 보스에 접근해 회전 연습을 시작하고 `R`로 저항합니다. 첫 번째 플레이어는 초록색 **RESCUE POINT**에서 `E`를 유지합니다.

다섯 단계를 모두 마치면 보스전이 시작됩니다.

## 전투 조작

`WASD` 이동, 마우스 시점, `Shift` 질주, `Space` 회피, 왼쪽/오른쪽 클릭 약/강공격, `Tab` 부위 선택, `Q` 자세 전환, `F` 공동 당기기, `E` 구조, `R` 회전 저항입니다.

## 알려진 범위

Windows 전용 프로토타입입니다. 현재는 서버 IP 직접 접속이며 초대 코드와 재접속 기능이 없습니다. 화면 안내는 영어입니다. 이 패키지에는 개발용 튜토리얼 건너뛰기 버튼이 없습니다.

보스 모델의 외부 배포 권한은 아직 확인되지 않았습니다. 권한이 확인되기 전에는 프로젝트 내부 시험에만 사용하세요.
