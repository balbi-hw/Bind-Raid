# 08. 2인 튜토리얼

상태: 기능 구현 및 2클라이언트 자동 진행 확인 · 근거: 프로토타입 기획서 §3–4, §7, §9

## 목표

두 플레이어가 3~5분 안에 사슬 거리 경고, 유연/고정 전환, 공동 당기기, 구조를 각각 한 번 경험한 뒤 보스전에 들어간다. [기획] 낚아채기와 회전의 전조·대응도 짧게 소개한다. [기획 + 명세 제안]

## 순서 [명세 제안]

| 단계 | 플레이어에게 보이는 목표 | 완료 조건 |
|---|---|---|
| 1. 연결 이동 | 서로 멀어져 7m 긴장 경고를 보고 다시 접근 | 양쪽 화면에서 긴장→여유를 확인 |
| 2. 자세 | 각자 고정·유연 전환 | 두 사람 모두 한 번씩 전환 |
| 3. 공동 당기기 | 표시된 보스 더미 양측으로 이동해 동시에 유지 | 유효 각도·0.8초 겹침으로 게이지 완료 |
| 4. 낚아채기 | 전조를 보고 접근하거나 낚아챔 후 공동 대응 | 대응 경로 하나 성공 |
| 5. 구조 | 회전/전투 불능 연습 대상에 접근해 구조 | 자유 플레이어 구조 완료, 잡힌 플레이어 역할 안내 확인 |

튜토리얼 전용 더미의 피해는 사냥 실패를 만들지 않는다. 실패 시 같은 단계로 즉시 재시도하며 실패 이유를 짧게 보여 준다. 한 사람만 목표를 달성해도 다음 단계로 넘어가지 않는다. [명세 제안]

## UX 규칙

- 화면에는 그 시점에 각 플레이어가 할 수 있는 행동 하나를 우선 표시한다.
- 당기기 실패 때는 각도·자세·접지·동시 입력 중 바로 고칠 항목을 표시한다.
- 짧은 안내는 텍스트·아이콘으로 제공하고 자막 크기 옵션을 적용한다.
- 개발자 단축 진행은 내부 빌드에서만 허용한다. 외부 사용성 시험에는 노출하지 않는다. [명세 제안]

## 완료 기준

1. 두 클라이언트의 단계 번호와 완료 상태가 일치한다.
2. 각 필수 행동을 최소 한 번 성공한 뒤에만 보스전이 시작된다.
3. 8쌍 외부 테스트에서 단계별 실패 횟수·소요 시간·도움말 사용 여부가 기록된다.
4. 테스트 대상 대부분이 3~5분 안에 완료하는 것을 초기 목표로 삼고, 초과 원인을 분석한다. [가정]

## 현재 구현 범위

서버가 다섯 단계의 완료를 판정하고 두 클라이언트에 같은 단계 번호를 동기화한다. 사슬 거리와 자세 전환은 각 플레이어의 실제 상태를 확인한다. 공동 당기기는 기존 앞다리 감김·0.8초 동시 입력·제압 판정을 사용한다. 낚아채기는 사슬이 긴장하면 연습 기술을 시작하고, 사전 회피 또는 사후 공동 제압으로 넘어간다. 구조 단계에서는 두 번째 플레이어가 회전에 잡히고 첫 번째 플레이어가 구조 지점에서 E를 유지한다. 연습 중 다운은 복구하며, 모든 단계를 마치면 두 플레이어가 함께 전투에 들어간다.

서버 1개와 클라이언트 2개의 자동 진행 시험에서 다섯 단계와 전투 전환을 확인했다. 실제 사람이 조작하는 3~5분 목표, 도움말 이해도, 역할 교대, 전용 더미/위치 표식은 아직 검증하거나 구현하지 않았다. 현재 빌드는 개발용이며 건너뛰기 버튼을 포함한다.
