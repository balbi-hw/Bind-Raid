# 05. 코끼리형 첫 보스 ‘쇄아’

상태: 구현·플레이 검토 대기 · 근거: 프로토타입 기획서 §3, §6, §8; GDD §6

## 전장·부위·페이즈

단일 전장과 코끼리형 보스 1종을 사용한다. 몸통·코·앞다리는 독립 피격 부위이며 보스 HP와 부위 내구도를 함께 갱신한다. 코·앞다리 파괴는 관련 기술의 빈틈을 늘리되 필수 대응을 없애지 않는다. [기획 + 명세 제안]

| 페이즈 | HP | AI 변화 |
|---|---|---|
| 1: 학습 | HP > 50% | 기본 3기술 중심, 사슬 기술을 단독으로 제시 |
| 2: 연계 강화 | HP ≤ 50% | 사슬 기술 빈도 증가, 기본 기술과 연계하되 연속 구속 금지 |

페이즈는 HP가 50% 이하로 내려간 서버 틱에 한 번 전환한다. 프로토타입은 GDD의 3페이즈를 구현하지 않는다. [기획 + 명세 제안]

## AI 실행 계약 [명세 제안]

`Select → Telegraph → Active → Resolve → Recovery` 순서로 공격한다. 전조가 시작되면 기술 ID·대상·판정 예정 틱을 양쪽에 전송한다. `Recovery`는 주요 기술 뒤 최소 2초. 잡기·낚아채기 중 다른 잡기 기술을 시작하지 않는다. 같은 구속 기술을 연속 선택하지 않는다. 연속 조작 불능의 총 길이는 6초 이하. 선택 가중치, 사거리, 피해량은 데이터 자산에서 조절한다. 페이즈 2에서도 회피 불가능한 즉시 피해를 만들지 않는다.

## 기술별 계약

| 기술 | 전조 [초, 초기 가정] | 판정·대응 | 실패 결과 |
|---|---:|---|---|
| 발 구르기 | 1.2 | 표시된 원형 범위 안의 플레이어에게 판정. 밖으로 이동/구르기 | 피해·짧은 넘어짐 |
| 직선 돌진 | 1.5 | 진행선을 고정한 뒤 돌진. 측면 회피 가능. 벽 충돌 시 보스 경직 | 충돌 피해 1회 |
| 코 휘두르기 | 1.0 | 코가 휘두르는 방향·범위를 표시하고 애니메이션 판정 시각과 동기화 | 피해·밀침 |
| 사슬 낚아채기 | 1.4 | 코가 판정 경로를 조준. 사전 접근으로 여유 `<7m`를 만들면 회피. 낚아챈 뒤 유효 각도·공동 당기기로 코 제압 가능 | 성공 대응 없으면 두 플레이어를 속도 상한 내에서 끌고 각자 피해 1회 |
| 한 명 회전 | 1.8 | 한 명만 잡음. 자유 플레이어가 보스에 접근해 경로 `<7m`를 만들고 구조; 잡힌 플레이어는 속도 저하 입력 | 자유 플레이어가 안전 경로를 못 만들면 원심력 피해 1회, 잡힌 플레이어 착지 피해 1회 |

피해에 최대 HP 비율의 고정 상한을 두지 않으며, 공격력·방어력과 기술별 기본 피해로 계산한다. 같은 기술 인스턴스로 같은 플레이어에게 두 번 적용하지 않는다. 강제 이동 속도 상한을 둔다. 실제 피해량·반경·돌진 거리·속도 저하 입력 창은 데이터 값이며 검토 후 튜닝한다. [사용자 검토 반영]

## 낚아채기·회전의 우선 규칙

- 낚아채기 중 감김점은 일시 중지한다. 공동 제압 성공 시 코 경직과 공격 창이 생기고 기술 피해는 취소한다. [기획]
- 회전 중 **둘 다 잡히는 상태는 금지**한다. 자유 플레이어가 종료 판정 전에 사슬 경로를 `<7m`로 낮추면 원심력 피해 0이다. 잡힌 플레이어의 착지 피해는 조기 구조 성공 시 0이다. [기획 + 명세 제안]
- 잡힌 플레이어는 일반 당기기를 할 수 없으므로 회전 도중 공동 제압은 발생시키지 않는다. 기존 앞다리 감김은 기술 종료 후 유효하면 복귀시킨다. [검토 필요]
- 회전 피해의 ‘원심력’은 거리·장력 조건을 이용한 단일 판정이며 실제 물리 속도에서 직접 계산하지 않는다. [기획 + 명세 제안]

## 완료 기준

1. 5개 기술마다 전조·대응 성공·피격 경로를 각 20회 이상 재현한다.
2. 전조 그래픽과 실제 범위·판정 시각이 일치한다.
3. 낚아채기의 사전 회피와 사후 공동 당기기가 둘 다 성공 가능하다.
4. 회전에서 동시 이중 잡힘이 0건이고 `<7m` 안전 경로에서는 자유 플레이어 피해가 0이다.
5. 같은 기술의 중복 피해와 6초 초과 연속 조작 불능이 없다. 피해는 공격력·방어력 변경에 따라 일관되게 계산된다.

## 현재 구현과 검증

서버가 다섯 기술을 `Idle → Telegraph → Active → Recovery`로 처리한다. 전조 시간·피해·범위·강제 이동 상한은 `Assets/Settings/BossSettings.asset`에서 조정한다. 페이즈 2는 HP 50% 이하에 한 번 시작하며 사슬 기술의 선택 빈도가 높아진다. 주요 기술 뒤 회복 시간은 최소 2초다. 보스 외형은 임시 도형이다.

두 인스턴스에서 발구르기·코 휘두르기 피해, 돌진 이동, 낚아채기 사전 회피·사후 피격, 회전 잡힘·조기 구조·안전 거리 피해 0·착지 피해, 페이즈 2 전환의 대표 경로를 검증했다. 명세의 기술별 20회 반복, 지연·손실 조건과 실제 화면에서 전조 범위가 정확하게 읽히는지는 아직 수용 시험 전이다.
