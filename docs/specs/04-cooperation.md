# 04. 자세·공동 당기기·구조

상태: 공동 당기기 구현·회전 구조 연결 대기 · 근거: 프로토타입 기획서 §4–5, §8; GDD §5

## 사슬 자세 [기획]

플레이어는 `유연`과 `고정`을 전환한다. 행동 가능 상태에서 입력하면 0.4초 선행 동작 뒤 전환하며, 재사용 대기 1초를 둔다. 고정은 이동 속도가 초기값으로 15% 줄고 공동 당기기를 할 수 있다. 잡힘·전투 불능·넘어짐 중에는 전환할 수 없다. 자세는 플레이어별로 독립이다.

## 공동 당기기 [기획 + 명세 제안]

서버는 매 틱 다음을 모두 확인한다: ① 두 플레이어가 고정 자세, ② 둘 다 접지·행동 가능, ③ 보스 기준 두 위치의 벌어진 각도가 80~160도, ④ 두 사람의 당기기 입력 유지가 **연속 0.8초 이상 겹침**, ⑤ 유효 감김 또는 낚아챔 대응 창, ⑥ 해당 부위 면역 시간이 끝남. 하나라도 거짓이면 제압 게이지를 올리지 않는다. 각도는 보스 중심에서 양 플레이어로 향하는 수평 벡터의 내각이다. [명세 제안]

성공 시 제압 게이지를 누적하고, 완료 시 보스를 경직시키며 같은 부위를 25초 면역 처리한다. 한 명만 당겨서는 누적되지 않는다. 게이지 최대값·누적/감쇠 속도는 데이터 자산의 플레이테스트 값이다. [기획 + 명세 제안] 입력 보정은 서버 시각 최대 100ms이며 서버가 모든 조건을 재검증한다. [기획]

실패 이유는 `NotBraced`, `NotGrounded`, `InvalidAngle`, `NoSharedHold`, `NoAnchor`, `PartImmune`, `PlayerDisabled` 중 하나로 개발 HUD·로그에 남긴다. 여러 이유가 겹치면 모두 기록하되 UI에는 플레이어가 바로 고칠 수 있는 이유를 우선한다. [명세 제안]

## 구조 [기획 + 명세 제안]

| 대상 | 구조 조건 | 성공 결과 | 중단 조건 |
|---|---|---|---|
| 전투 불능 동료 | 자유 플레이어가 표시된 범위에서 대상 플레이어의 누적 전투 불능 횟수 × 3초 상호작용 유지 | 대상 HP를 시험용 회복값으로 복구 | 구조자 피격·범위 이탈·입력 해제·연결 종료 |
| 회전 기술에 잡힌 동료 | 자유 플레이어가 보스 인근 표시 지점에서 기술별 구조 입력 유지 | 기술을 조기 종료하고 착지·원심력 피해 0 | 구조자 피격·범위 이탈·기술 판정 시각 도달 |

전투 불능 구조 횟수 제한은 없다. 구조 시간은 대상 플레이어별 첫 전투 불능 3초, 이후 3초씩 증가한다. [사용자 검토 반영] 회전 구조의 거리와 유지 시간은 기획서에 없으므로 보스 기술 데이터에서 조정한다. `넘어짐`은 짧은 자동 회복이며 전투 불능 구조 대상이 아니다. [검토 필요]

## 이벤트·완료 기준

서버 이벤트는 `StanceChanged`, `PullAttemptStarted/Failed/Completed`, `StaggerTriggered`, `RescueStarted/Cancelled/Completed`를 사용한다. 한 번의 구조·제압은 고유 ID로 한 번만 적용한다. [명세 제안]

1. 조건 6개 중 하나씩 빠뜨린 시험에서는 제압이 일어나지 않고 해당 이유가 남는다.
2. 두 사람이 조건을 유지하면 누적·경직·25초 면역이 순서대로 발생한다.
3. 피격·거리 이탈·입력 해제로 구조가 취소되며, 대상별 요구 시간이 3초씩 증가하는지 확인한다.
4. 회전 구조와 전투 불능 구조의 비용·결과가 혼동되지 않는다.

## 현재 구현과 검증

- `Q`로 자세를 전환한다. 서버가 0.4초 선행 동작과 1초 재사용 대기를 판정하며, 고정 자세 이동 속도는 15% 줄어든다. `F` 당기기 입력은 서버에 전달된다.
- 서버가 두 사람의 자세·접지·행동 상태·80~160도 각도·동시 입력 0.8초·유효 앵커·부위 면역을 검사한다. 실패 이유는 개발 HUD와 로그에 표시한다. 게이지 기본값은 최대 100, 초당 80 증가·30 감소이며 설정 에셋에서 조정한다. 완료 시 보스는 3초 경직되고 같은 부위가 25초 면역이 된다.
- 두 인스턴스 시험에서 단독 당기기 차단, 공동 당기기 성공, 보스 경직, 같은 부위 면역을 확인했다. 조건별 규칙은 100회 반복 검증했다.
- 전투 불능 구조는 기존 3/6/9초 누적 규칙대로 동작하며 시작·취소·완료 사건을 기록한다. 회전 기술에서 잡힌 동료의 구조와 실제 코 낚아챔 공격은 아직 보스 기술이 없어 연결하지 않았다. 실제 플레이 감각은 사용자 검토가 필요하다.
