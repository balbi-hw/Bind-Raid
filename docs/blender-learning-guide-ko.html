자료 조사일 2026.11.01 · 입문자용 · 주 3회 × 60~90분 · 최종 목표 5~10초 캐릭터 애니메이션

먼저 알아둘 것

이 파일은 영어 원문의 전문 번역본이 아닙니다. 원문에서 확인한 핵심 개념을 한국어로 요약하고, 초보자를 위한 별도의 실습 안내를 덧붙인 학습 문서입니다. 영상 자막 전체를 확보하거나 모든 영상을 재생 검수한 것은 아니므로, 영상별 해설은 공개 소개·목차·설명에서 확인 가능한 범위에 맞췄습니다.

리깅 대상은 보통 입체 메시가 있는 3D 모델입니다. JPG·PNG만 있다면 먼저 모델링 또는 평면 변형용 메시 준비가 필요합니다. 이 과정은 기본 도형 또는 준비된 3D 캐릭터를 사용합니다.

선정 기준

A · 공식 자료: Blender Studio와 Blender 매뉴얼을 도구 사용법의 기준으로 삼았습니다.

B · 교육기관: Animation Mentor, AnimSchool, 캐나다 국립영화위원회(NFB)의 글로 움직임 원리를 보완합니다.

C · 전문 제작자: CGDive 영상은 웨이트 작업을 보충하는 선택 자료입니다. 기관의 공식 검증을 받은 자료라는 뜻은 아닙니다.

버전과 이용 조건

공식 강좌 제목은 4.5 LTS이지만 일부 애니메이션 장은 5.2 기준으로 갱신되어 있습니다. 연결된 예제 파일의 버전을 먼저 확인하세요. 2.80 영상은 개념 복습용입니다.

주요 자료는 공개 무료 페이지 또는 Free 표시 강의입니다. Studio 상단의 구독 안내와 개별 무료 강의는 구분하세요. 로그인·지역 제한·향후 공개 정책 변경은 있을 수 있습니다.

검증 범위: 게시 주체, 검색에 공개된 제목·목차·설명, 접근 가능한 본문을 확인했습니다. 일부 Blender 페이지는 조사 도구의 직접 열기가 실패하여 검색 색인으로 대조했습니다. 아래에 개별 확인 범위를 적었습니다. 이는 사용자 브라우저에서도 유료 또는 접근 불가하다는 뜻은 아닙니다. 한국어 자막 제공 여부는 확인하지 않았습니다. 모든 원문은 영어입니다.

본문과 스타일은 이 파일에 포함되어 오프라인에서도 읽힙니다. 원문·영상 재생은 인터넷 연결이 필요합니다.

  • 호: 손과 머리의 이동 궤적이 의도 없이 꺾이지 않는지 살핍니다.
  • 후속·겹침 동작: 몸통이 멈춘 뒤 손이나 꼬리가 뒤늦게 정리되도록 관찰합니다.

A 공식단계별 실습4주

R08 · Creating a Skeleton
